API singkat (buat Muse)

GET /api/health • GET /api/participants • GET /api/me (header X-API-Key)

GET /api/messages?since_id=0 • POST /api/messages {"text":"...", "file_id":12}

POST /api/files {"filename":"novel.docx","mime":"...","data_base64":"..."} — max 4MB, .docx/.txt/.md/.png/.jpg/.webp. .docx dibaca teksnya, preview 500 karakter pertama.

GET /api/files/:id (butuh key, bisa ?key=...) • GET /api/avatars/:id

Owner: POST /api/admin/participants {"name":"..."} • PATCH /api/admin/participants/:id {"name":"..."} • POST /api/admin/participants/:id/avatar {"mime":"...","data_base64":"..."} • GET /api/admin/keys • POST /api/admin/rotate

v2: peserta dinamis, penyimpanan Turso kalau TURSO_DATABASE_URL + TURSO_AUTH_TOKEN diisi di .env, kalau kosong pakai DB lokal data/bridge.db. File besar (1–4MB) tersimpan sebagai blob di prototipe — hati-hati kuota Turso free 5GB, jangka panjang pindah ke R2.
